# MotionLens — Landing

**The visual context layer for AI agents.** MotionLens turns recordings, live websites, and interfaces into structured **Motion Blueprints** — annotated storyboards, layered motion specs with exact timings, and production-ready code — that AI coding agents (Claude Code, Cursor, Windsurf, Codex) can build from.

This repo is the marketing landing page.

## Stack
- Next.js 16 (App Router, Turbopack)
- Tailwind CSS v4
- Framer Motion (`motion/react`)
- three.js / React Three Fiber

## Develop
```bash
npm install
npm run dev
```

## Deploy
Auto-deploys to **Vercel** on every push to `main`.
